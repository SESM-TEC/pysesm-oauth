# PySESM data sync: OAuth information pages

Home page and privacy policy of the Google OAuth application
"PySESM data sync", which members of the SESM research group (Tecnológico de
Costa Rica) use with rclone to copy the PySESM project's research data to and
from its Google Drive folder. Google requires both pages, hosted on an
authorized domain, before an External OAuth application can be published.

Published with GitHub Pages:

- Home page: https://sesm-tec.github.io/pysesm-oauth/
- Privacy policy: https://sesm-tec.github.io/pysesm-oauth/privacy.html
- Authorized domain: `sesm-tec.github.io`

The app name in the pages must match the OAuth consent screen exactly. Never
commit the OAuth client ID or secret here.
